# Uporabniski Vmesnik

Preprosta Android aplikacija za štetje in prikaz uporabniškega vmesnika.

## Opis

Aplikacija omogoča štetje pritiskov na gumb, prikaz trenutnega števca, ponastavitev ter dinamično spreminjanje barv gumbov glede na stanje števca.

## Funkcionalnosti

- Prikaz obvestila (Toast) ob pritisku na gumb
- Štetje pritiskov in prikaz vrednosti
- Dinamična sprememba barve gumba glede na sodo ali liho vrednost števca
- Ponastavitev števca na nič in ponastavitev barve gumba

## Zahteve

- Android Studio (priporočena novejša različica)
- Android SDK (minimum API 24 ali novejši)
- Java / JDK 17

## Namestitev in zagon

1. Klonirajte ali prenesite projekt.
2. Odprite projekt v programu Android Studio.
3. Počakajte, da se zaključi sinhronizacija Gradle.
4. Zaženite aplikacijo na emulatorju ali povezani napravi Android.
